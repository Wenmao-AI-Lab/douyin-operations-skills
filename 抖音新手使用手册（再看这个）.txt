第0章｜先搞懂这个技能包是什么
────────────────────────────────────────────────────

这是一套围绕「抖音运营全流程」组织的 AI 技能包，覆盖 8 大环节：
账号定位与起号 → 选题与热点追踪 → 脚本与文案创作 → 拍摄剪辑与素材
→ 发布与多平台分发 → 互动涨粉与私信 → 数据复盘与账号诊断 → 合规与风控。

共 32 个技能。每个技能是一个「会干活的 AI 助手」，你用自然语言下指令，
它按自己的流程帮你产出结果。

┌──────────────────────────────────────────────────┐
│ ⚡ 小白怎么理解「技能」：                                    │
│    你可以把它当成一位随时待命的同事。                             │
│    你说「帮我写一条美食探店的口播脚本」，                           │
│    它不会反问一堆问题，而是直接按步骤把成品交给你。                      │
└──────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────┐
│ ⚠️ 关于 🟡 标记的技能：                                   │
│    数据榜 / 查询类需要联网，评论与发布类需要登录态，                    │
│    下载 / 拆解 / 剪辑类需要装对应运行环境。                       │
│    每个技能的详解里都写了要准备什么，照着做即可；                       │
│    其余 14 个 🟢 技能装好就能用，不花一分钱。                      │

第1章｜安装：一次性装好全部技能
────────────────────────────────────────────────────

① 找到本技能包文件夹，每个技能是一个子文件夹（内含 1 个 .zip + 1 份使用说明）。
② 把技能夹整体复制进智能体的 skills 目录（用户级 ~/.workbuddy/skills/ 或项目级 .workbuddy/skills/）。
③ 重启或刷新智能体，在对话里直接 @ 技能名，或用自然语言描述需求即可调用。

┌──────────────────────────────────────────────────┐
│ ⚠️ 安装成功的判断标准：                                    │
│    ① 对话框里 @ 技能名，能自动补全出来                          │
│    ② 说一句需求，它直接给成品，而不是反问你                         │
│    ③ 技能目录下能看到 SKILL.md 这个文件                      │
│    三条都满足 = 装好了。缺哪条，重启一次再看。                       │
└──────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────┐
│ 💡 装完先做一件事：                                       │

▌01_账号定位与起号（2 个）

【人设与赛道规划师】
  所属分类：抖音运营 · 账号定位与起号
  技能标识：personal-ip-positioning
  依赖门槛：🟢 零门槛 — 无需 API、密钥或付费，安装即用。
  干什么的：个人 IP 定位引擎，覆盖赛道选择器、人设画像、差异化定位、内容方向矩阵、变现路径规划与 100 天起步计划。不知道自己该做什么账号、和别人差在哪，先跑它。

第5章｜新手常见问题 FAQ
────────────────────────────────────────────────────

Q1：技能装了但调不动？
    → 确认 .zip 已解压进 skills 目录、重启智能体，并用 @技能名 或在提示里点名。

Q2：热榜/飙升榜查不出来？
    → 这类技能需要联网。先确认电脑能上网，再按技能内指引操作；
      数据服务偶尔繁忙，等几分钟重试即可。

Q3：评论抓不到 / 提示要登录？
    → 评论与竞品类技能需要登录态（cookie 或扫码）。首次使用按技能内
      指引完成一次绑定，之后会记住状态。

Q4：视频下载 / 拆解技能跑不起来？
    → 这类技能依赖本机运行环境（如 yt-dlp、Whisper），技能文档里写了
      装什么、怎么装，照做一次即可，之后不用再管。

Q5：自动上传发布没反应？
    → 排查三步：①是否按指引安装命令行工具 ②是否完成扫码登录
      ③登录是否过期（重新扫码一次）。首次必须扫码登录一次。
