【技能名称】抖音评论数据采集
【所属分类】06_互动涨粉与私信
【技能标识】douyin-comments
【依赖门槛】🟡 需配置 cookie 与运行环境（见第七节）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、这个技能是干什么的
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  抓取抖音视频的评论列表：纯 HTTP + cookie + 签名实现，不启动
  浏览器，速度快、占用低。输出结构化 JSON 与按点赞排序的
  Markdown 摘要，用于评论区洞察、用户反馈收集、选题灵感挖掘。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
二、核心功能
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ① 按 video_id 抓取评论列表（分页拉取）
  ② 输出 JSON 原始数据 + 按点赞排序的 Markdown 摘要
  ③ 供后续评论分析 / 痛点总结 / 内容讨论分析使用

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
三、详细功能说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  调用方式与参数见技能包内 SKILL.md 与 scripts/fetch_comments.ts；
  抓取流程由智能体按 SKILL.md 工作流自动执行。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
四、安装三步
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. 找到本技能所在文件夹「抖音评论数据采集」，解压其中的
     douyin-comments.zip；
  2. 将解压出的技能目录放入智能体的技能目录（skills/）；
  3. 重启 / 刷新智能体，在对话中粘贴视频链接即可调用。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
五、怎么用
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ▸ 触发场景：想分析某条爆款视频评论区风向、收集用户痛点时。
  ▸ 直接说：「抓取这条视频的评论」+ 视频链接；
    「把评论按点赞排序给我一份摘要」。
  ▸ 你能拿到：评论 JSON 数据 + 点赞排序 Markdown 摘要。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
六、依赖门槛
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  🟡 需配置 —— 需提供自己抖音账号的登录 cookie（浏览器 F12
  复制即可）并安装 Node.js 运行环境；仅抓取公开评论数据，
  请控制频率、合理使用。
